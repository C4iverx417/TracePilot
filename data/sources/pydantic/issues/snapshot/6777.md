## Comment by hramezani [CONTRIBUTOR]

<https://github.com/pydantic/pydantic/issues/6777#issuecomment-1644156936>

After `Pydantic V2`, settings management has been moved to a separate package [pydantic-settings](https://github.com/pydantic/pydantic-settings).

You can install this package by `pip install pydantic-settings`.

Here is the [pydantic-settings documentation](https://docs.pydantic.dev/2.0/usage/pydantic_settings/)

If you want to use `Pydantic V1` settings management, you can use it like:

`from pydantic.v1 import BaseSettings`
