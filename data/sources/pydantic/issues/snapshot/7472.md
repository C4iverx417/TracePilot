Hi @amitsubhashchejara,

Thanks for your question. Looks like you've got a dependency conflict going on. If [this](https://github.com/chroma-core/chroma/tree/main) is indeed the package you're mentioning, its latest version requires Pydantic <2.0, whereas you have v2.30 installed. If you install Pydantic v1.10, this error should go away.
